# Data_Eng

### 1. Azure Cloud (ADF, SQL DB, etc.)
Azure Data Factory (ADF): Это облачный сервис для интеграции данных, который позволяет создавать, управлять и автоматизировать рабочие процессы по перемещению и преобразованию данных. ADF поддерживает различные источники данных и позволяет создавать ETL-процессы (извлечение, преобразование, загрузка) с использованием визуального интерфейса или кода.
Azure SQL Database: Это управляемая облачная версия Microsoft SQL Server, предоставляющая высокую доступность, безопасность и автоматическое масштабирование. Azure SQL Database позволяет хранить и обрабатывать структурированные данные с использованием SQL, а также интегрироваться с другими сервисами Azure.
Другие компоненты Azure: В Azure также есть множество других сервисов, таких как Azure Blob Storage для хранения неструктурированных данных, Azure Data Lake для больших данных и Azure Synapse Analytics для аналитики и обработки больших объемов данных.

### 2. Databricks (Python/PySpark/SQL)
Databricks: Это облачная платформа для обработки больших данных и аналитики, основанная на Apache Spark. Databricks позволяет пользователям легко создавать и управлять кластерами Spark для выполнения анализа данных, машинного обучения и обработки потоковых данных.
Python: Один из языков программирования, поддерживаемых Databricks. С помощью Python можно писать скрипты для обработки и анализа данных, а также создавать модели машинного обучения.
PySpark: Это API для работы с Apache Spark на Python. PySpark позволяет выполнять распределенные вычисления и обрабатывать большие объемы данных с использованием функциональности Spark.
SQL: Databricks также поддерживает SQL-запросы, что позволяет пользователям выполнять анализ данных с помощью привычного синтаксиса SQL, что упрощает работу для аналитиков и разработчиков.

### 3. Data Visualization with Power BI
Power BI: Это инструмент для визуализации данных и бизнес-аналитики от Microsoft. Он позволяет пользователям создавать интерактивные отчеты и дашборды, используя данные из различных источников, включая базы данных, Excel и облачные сервисы.
Функциональность: Power BI предоставляет широкий набор инструментов для визуализации данных, включая графики, таблицы и карты. Пользователи могут легко настраивать визуализации и взаимодействовать с данными через фильтры и срезы.
Интеграция: Power BI хорошо интегрируется с другими сервисами Microsoft и Azure, что позволяет легко импортировать и анализировать данные из Azure SQL Database, Azure Data Lake и других источников.

### 4. Azure DevOps (SCRUM, CI/CD)
Azure DevOps: Это набор инструментов для управления проектами, разработки и развертывания программного обеспечения. Он включает в себя функции для планирования, разработки, тестирования и развертывания приложений.
SCRUM: Это методология управления проектами, основанная на Agile. Azure DevOps поддерживает SCRUM через планирование спринтов, управление задачами и отслеживание прогресса.
CI/CD (Continuous Integration/Continuous Deployment): Это практика автоматизации процессов интеграции и развертывания кода. Azure DevOps предоставляет инструменты для настройки CI/CD, позволяя разработчикам автоматически тестировать и развертывать код при каждом изменении в репозитории. Это помогает улучшить качество кода и ускорить его доставку.
